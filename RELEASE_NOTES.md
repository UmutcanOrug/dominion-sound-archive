Dominion Sound Archive 1.0.7 for Foundry VTT v13 and SWADE.

Automatic Attack now recognizes public weapon attack cards from SWADE Tools 2.3.0 as well as native SWADE. Wounds still trigger Hurt. Incapacitated, Dead and Defeated trigger Death.

Add a partial name such as Auranii to cover Auranii Legionarii and Auranii Rifleman. For a particular event, the longer matching rule with clips wins. An Actor's individual Attack, Hurt or Death clips take priority over matching global sounds. Empty groups use the global rules, and existing Wounded clips work as personal Hurt audio.
